\\# 🛡️ Bank Security Awareness \\\& Departmental Risk Index







An interactive InfoSec dashboard built with Python and Streamlit to monitor security awareness training compliance, phishing simulation response metrics, and calculate departmental risk scores across banking operations.







\\## 🚀 Key Features



\\\* \\\*\\\*Executive Security Metrics\\\*\\\*: Real-time aggregation of training completion rates, phishing click rates, and report rates.



\\\* \\\*\\\*Risk Score Index\\\*\\\*: Dynamic formula highlighting high-risk business units needing targeted security awareness training.



\\\* \\\*\\\*Custom Dataset Ingestion\\\*\\\*: Drop-in support for uploading phishing campaign CSV logs.



\\\* \\\*\\\*Exportable Audit Reports\\\*\\\*: One-click CSV export for quarterly compliance reviews.







\\## 🛠️ Tech Stack



\\\* \\\*\\\*Language\\\*\\\*: Python 3.10+



\\\* \\\*\\\*Framework\\\*\\\*: Streamlit



\\\* \\\*\\\*Data Processing\\\*\\\*: Pandas, NumPy



\\\* \\\*\\\*Visualization\\\*\\\*: Plotly Express
